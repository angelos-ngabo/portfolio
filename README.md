## 📁 Featured Projects

A comprehensive digital agricultural platform connecting farmers, buyers, and warehouse agents.

**Key Features:**
- Multi-role dashboards (Farmers, Buyers, Warehouse Agents, Admin)
- Smart notification system with role-based alerts
- AI assistant for system information
- Agricultural market coordination

**Tech Stack:** Web Technologies, Database Systems, Dashboard Architecture

### 2. Complaint Management System (Java)
Enterprise-level complaint tracking system built with Java.

**Key Features:**
- Client-server architecture using Java RMI
- Role-based access control
- Status tracking (Pending, Resolved, Dismissed)
- Complaint submission and management

**Tech Stack:** Java Swing, Hibernate, MySQL, DAO, MVC Architecture

### 3. University Library Management System
Web-based library management system for AUCA.

**Key Features:**
- Student registration and authentication
- Book request and issuing system
- Admin dashboard for management
- Secure PHP backend with MySQL

**Tech Stack:** HTML, CSS, JavaScript, PHP, MySQL

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎨 Customization

### Personal Information

Update the following files with your information:
- `src/sections/Hero.tsx` - Name and tagline
- `src/sections/About.tsx` - Personal story and skills
- `src/sections/Projects.tsx` - Your projects
- `src/sections/Experience.tsx` - Work history
- `src/sections/Contact.tsx` - Contact details

### Styling

- Colors: Update Tailwind config in `tailwind.config.js`
- Fonts: Modify `src/index.css`
- Animations: Adjust Framer Motion settings

## 🚀 Deployment

### Vercel (Recommended)

2. Connect to Vercel

### Netlify
